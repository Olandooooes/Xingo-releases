## 场景与职责

对自己拥有或获得编辑授权的图片，用户可能只需要修复小范围污点、划痕或遮挡，不需要复杂的专业编辑工作流。我将本地处理组织为桌面工具，并配套官网、安装包、校验和反馈入口。

可核实技术是 Python、OpenCV、Pillow、NumPy。图像在本机处理；没有证据表明这是训练出的生成式修复模型。

## 操作与实现

```text
打开图片 → 框选区域 → 修复预览 → 需要时撤销 → 另存为
```

工具文档还包括同位置批量处理：先在样例中选择区域，再处理尺寸相同的图片。这个限制使选区位置可以对应，不能扩写为自动识别任意分辨率图片中的对象。

OpenCV 提供传统局部修复，Pillow / NumPy 参与图像处理流程。文档列出 TELEA 与 NS 选项；技术选择满足离线和局部修复需求，但复杂线条、人物面部和大面积遮挡不能可靠还原被遮挡的原始内容。
