# 我的回想录 · 微信小程序与独立产品站交付

[← 作品集首页](../PORTFOLIO.md) · [官网](https://yearrings.xingo.fun) · [版本与反馈](https://github.com/Olandooooes/Xingo-releases)

> 个人闭源项目。依据：公开发布说明、私库目录和构建清单。小程序实际可用功能以当前微信版本为准。

## AI 辅助开发工具与多端形态

个人项目主要使用 **ChatGPT、Codex**辅助需求梳理、代码理解、实现与调试，由我核对产品行为和发布边界。

产品入口是 **微信小程序**：运行于微信宿主中的 JavaScript / WXML / WXSS 客户端，通过服务端 API 获取应用能力，可按客户端 / 服务端（C/S）关系理解。配套独立 **Web 官网属于 B/S 形态**。小程序使用微信运行环境，不将其描述为本人分别开发的原生 iOS 和 Android 应用。
## 场景与产品范围

产品围绕个人回忆记录，以微信小程序作为使用入口，配套独立官网、隐私说明、版本归档和问题反馈。我维护产品实现及这些交付入口，避免把官网变化和小程序正式版本混为一谈。

源码目录可以核实 JavaScript / WXML / WXSS 页面，包含记录、回顾、人物和数据安全相关页面；页面文件存在不等于已核验的微信审核功能清单。

## 实现与交付组织

```text
微信小程序入口 → 记录与回顾相关页面
独立产品官网 → 介绍、隐私与使用入口
公开发布仓库 → 版本说明、源码追溯信息与反馈
```

仓库的 Node 脚本分别检查小程序、门户网站和独立产品站，并分别生成网站输出。这样网站改版与小程序发布可以分开追踪，避免把一次网站部署描述成一次微信审核上线。

公开归档 v1.0.5 由私有源码提交与部署记录建立追溯。该标签不是未经核实的微信公众平台审核版本号，审核日期和正式上线日期不凭标签推测。

## 数据边界与维护

公开页面提供隐私政策、用户协议和反馈路径；个人记录与服务端配置不进入发布仓库。源码归档、网站部署、小程序审核是不同证据，维护时需要分别确认。

当前材料不足以完整说明全部后端实现、存储配置或用户规模，因此本页不扩写这些细节。本次未登录小程序执行真实记录流程，也未重新运行仓库检查脚本。

## 如何体验

在微信搜索「我的回想录」，用虚构内容体验记录与回顾，再查看产品内的数据和隐私说明。官网仍作为产品入口；本项目不提供 Windows、macOS、Android 或 iOS 安装包。

后续可补充对应正式小程序版本的脱敏演示、审核记录和完整数据操作验收。任何设计示意都应与真实截图分开标注。
